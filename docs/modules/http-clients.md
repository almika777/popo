# Popo.HttpClients

## Ответственность

Модуль содержит HTTP-клиенты MOEX ISS, CBond и CBR, транспортные контракты MOEX, сериализацию дат и преобразование ISS-данных. Интерфейсы клиентов и внутренние модели принадлежат Core.

## Клиенты

- `IMoexHttpClient` / `MoexHttpClient` — запросы к MOEX ISS;
- `ICbondClient` / `CbondClient` — запросы к CBond;
- `ICbrHttpClient` / `CbrHttpClient` — запросы к ЦБ РФ.

`IMoexHttpClient` получает `securities`, `marketdata` и `marketdata_yields` отдельными
запросами по торговым режимам. Каждый набор кэшируется на пять минут в памяти процесса;
API и Jobs имеют независимые кэши. Объединение с сохранёнными справочниками выполняют
потребители по `SecId + BoardId`. Единого атомарного снимка этих наборов нет.
Текущая котировка `LQDT`/`TMON` кэшируется на час по `SecId + BoardId`.
История облигаций и сделки читаются с пагинацией по cursor. `GetLqdtIndexHistoryAsync`
получает два разных ряда с MOEX: официальную цену закрытия основной сессии `LEGALCLOSEPRICE` пая `LQDT`
из дневной истории торгов с первой даты 22.07.2022 и расчётную стоимость пая `LQDTM`
из истории индикатора с первой даты расчёта 22.07.2022. История LQDT читается страницами по 100
строк; клиент проверяет cursor, неизменность общего количества строк, корректность цены и отсутствие
нескольких строк за одну дату. `GetMoneyMarketFundPriceHistoryAsync` загружает дневную историю `LQDT` и `TMON`
(с 22.07.2022 и 12.07.2023 соответственно) и проверяет cursor, размер страниц, цену и уникальность даты.
`GetLqdtPriceHistoryAsync` остаётся обёрткой для совместимости. Для доходности удержания берётся `LEGALCLOSEPRICE` основной сессии;
`LQDTM` не подменяет цену инструмента, а свеча текущего незавершённого дня не используется.

`EFFECTIVEYIELD` MOEX запрашивается только как диагностическое поле и не участвует в рекомендации:
доходность облигации рассчитывается из денежных потоков. `ACCRUEDINT` используется как сумма в валюте
расчётов и сохраняет `null`, если MOEX не прислал значение; цена оферты берётся из сохранённого security snapshot. `SETTLEDATE`,
`FACEVALUEONSETTLEDATE` и `ACCRUEDINT` поступают в составе `securities`;
их согласованность по времени с отдельно загруженной `marketdata` клиент не гарантирует.

Регистрация клиентов выполняется через `AddPopoHttpClients`.

## Правила данных

Транспортные DTO MOEX находятся в `Popo.HttpClients/Contracts/Iss`, включая ISS-обёртки и JSON-атрибуты. `MoexIssClient` выполняет запросы и разбирает ответы. `MoexHttpClient` через `MoexContractMapper` возвращает внутренние модели `Popo.Core/Contracts/Iss`, не содержащие атрибутов формата ISS.
Преобразование ISS-строк выполняется через `MoexMapper`.
Временные значения MOEX обрабатываются специализированными converters и `MoscowTime`.
