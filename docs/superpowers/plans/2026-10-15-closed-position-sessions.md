# Closed position sessions implementation plan

**Goal:** Хранить и показывать завершённые сессии облигаций, рассчитанные отдельной автоматической/ручной джобой.

**Architecture:** Новый агрегат `ClosedPositionSessions`, отдельные Core-калькуляторы обычных облигаций, флоатеров и ЗО, собственные Storage providers, API и страница. Существующие расчёты открытых позиций не меняются.

## Согласованные правила

- Идентичность позиции: SecId + BoardId + CurrencyId. Нулевой остаток завершает сессию; повторная покупка начинает новую.
- Внутри дня сначала продаётся прежний остаток, затем учитываются покупки. Если продаж больше прежнего остатка, их остаток относится к покупкам этого дня; невозможная продажа считается ошибкой исходных данных.
- Купонный доход: сумма `количество × сумма купона / дни купонного периода × дни владения внутри периода`. День покупки включён, день продажи исключён. Пробел/неизвестная сумма/конфликт периодов делает результат неполным.
- Тело = чистая выручка + частичные амортизации − чистая стоимость покупок. Полное погашение из графика не начисляется и не закрывает сессию: владелец вносит финальную продажу.
- Итог = тело + оценка купонного дохода − комиссии обеих сторон. НКД из сделок и налоги не учитываются.
- Доходность = итог / сумма чистых покупок × 100; годовая = доходность × 365 / дни сессии. При нулевом сроке годовая оценка отсутствует.
- Пересчёт заново строит весь снимок из актуальных сделок, исправления/удаления устраняют устаревшие сессии. Публикация атомарна; при ошибке остаётся предыдущий снимок.

## Задачи

- [x] Core: контракты, построение сессий, интервалы владения, отдельные калькуляторы купонного дохода и амортизаций; тестовые сценарии до реализации.
- [x] Storage: отдельные entity/configuration/source/store; миграция только `dotnet ef migrations add`.
- [x] Jobs/API: Hangfire каждые 15 минут, запуск через API в ту же очередь, статус ручной задачи; тонкий controller.
- [x] Frontend: отдельные API client/page и ссылка в меню (сабагент).
- [x] Документация, сборка .NET и frontend. Тесты не запускать без явного запроса пользователя.

## Результат

`dotnet build Popo.sln -m:1 -p:OutputPath=bin/ClosedSessionsBuild/ --no-restore` — успешно, 0 предупреждений/ошибок.
`npm run build` — успешно, маршрут `/closed-positions` включён. Тестовые проекты скомпилированы; тесты не запускались.
Миграция сгенерирована штатной командой EF Core, к рабочей БД не применялась.
Ревью выявило неработающий при постановке через интерфейс атрибут блокировки: заменён явным distributed lock
на всё чтение/расчёт/публикацию. После исправления подтверждённых замечаний нет.

## Review focus

Частичные продажи и смена купона; закрытие/повторная покупка в один день; пробелы/дубли графика; частичная амортизация без двойного учёта погашения; валютные суммы без курса; исправление/удаление сделок и атомарность снимка.
