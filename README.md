# Popo

Popo — локальное приложение для учёта облигационного портфеля.

С его помощью можно:

- загружать данные об облигациях и ценах;
- вести сделки и денежные операции;
- рассчитывать позиции и доходность портфеля;
- подбирать облигации по заданной стратегии.

## Быстрый запуск на Windows

Для запуска нужен установленный и запущенный [Docker Desktop](https://www.docker.com/products/docker-desktop/).

1. Скачайте или клонируйте репозиторий.
2. Откройте файл `start-popo.bat` двойным кликом.
3. Дождитесь открытия приложения в браузере.

Скрипт автоматически запустит базу данных, серверную часть, фоновые задачи и интерфейс. При первом запуске также применяются миграции базы данных и выполняется первичная загрузка данных.

Первичная загрузка может занять несколько минут. Её состояние отображается в приложении отдельно для каждой фоновой задачи. До завершения загрузки часть данных может быть недоступна или неполной; приложение при этом не блокируется.

Приложение доступно на компьютере по адресу [http://localhost:7955](http://localhost:7955).
После запуска актуальный адрес для телефона отображается ссылкой в правой части верхнего меню.
Открытым для сети остаётся только интерфейс приложения;
PostgreSQL, API и фоновые задачи наружу не публикуются.
В приложении нет аутентификации, поэтому используйте этот адрес только в доверенной локальной сети и не открывайте его в Интернет.

## Остановка

Для остановки приложения откройте `stop-popo.bat`.

Остановка не удаляет сохранённые данные.

Проект распространяется по лицензии [0BSD](LICENSE).
