# Правила работы агента

## Перед изменениями

- Прочитать `README.md`, `docs/project.md`, `docs/conventions.md` и документацию затронутого модуля.
- Всегда прочитать все ADR из `docs/adr/` до начала работы в проекте.
- Если данных не хватает — задать 1–2 точечных вопроса.
- Не выдумывать API, типы и структуру проекта.

## Работа

- Если задача ясна — сразу выполнять.
- Подтверждение запрашивать только при существенной неоднозначности.
- Перед кодом дать план не более чем из 3 предложений.
- Не добавлять работу вне задачи.
- Если принятое решение признано ненужным, удалить его упоминания из документации.

## Проверки

- Сборку можно запускать без дополнительного запроса пользователя.
- Тесты и другие проверки запускать только по явному запросу пользователя.

## Общение

- Коротко, грубо и по факту.
- Без приветствий, лести и лишних речевых оборотов.
- После работы указать изменённые файлы и результат запрошенных проверок.
